# S. S. Industrial Services - Enterprise Website

Responsive multi-page website for S. S. Industrial Services (chemicals and raw materials for water treatment plants), built during my summer internship, July 2026.

**Live site:** https://nikhil-2301-dot.github.io/ss-industrial-website/

## Pages
- Home - hero section, featured products, chatbot prototype
- About Us - company overview
- Products - product grid with specification pop-ups (data in `products.js`)
- Contact - enquiry form (Formspree) and Google Maps embed

## Built with
HTML5, CSS3 (Flexbox, Grid, CSS variables) and vanilla JavaScript. No build step - open `index.html` in a browser to run it locally.

## Run locally
Download or clone the repo and open `index.html`.
